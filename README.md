# Calories Tracker

An application for tracking calories intake and user hydration. Created with the aim of developing in **React Native**.

## 🛠 Technologies

- React Native + Expo
- TypeScript
- Zustand
- Expo SQLite
- React Hook Form + Zod
- Jest + jest-expo
